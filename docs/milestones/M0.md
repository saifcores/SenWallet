# M0 — Socle du monorepo

Branche : `milestone/m0-monorepo-foundation` · Taille : S

## Ce qui a été construit

- Monorepo Gradle Kotlin DSL avec wrapper 9.8.2, catalogue `gradle/libs.versions.toml` (Java 25, Spring Boot 4.1.2, JUnit 6, AssertJ, jqwik, ArchUnit, Testcontainers) et toolchain Java 25 résolue par foojay (ADR-15).
- `build-logic/` avec deux plugins de convention :
  - `senwallet.java-library` : Java pur, toolchain 25, `-Xlint:all -Werror`, JUnit Platform, JaCoCo (XML + HTML) ;
  - `senwallet.spring-service` : le précédent + plugin Spring Boot, BOM, starter et starter-test.
- `platform/shared-kernel` (package `sn.senwallet.shared`, Java pur) : `Money` (`BigDecimal` à l'échelle de la devise, décimales rejetées, conversion `toMinorUnits()` vers `BIGINT`, ADR-16), `Currency` (XOF, exposant 0), identifiants typés `AccountId`, `WalletId`, `TransactionId`, `CustomerId`, `LedgerId`, interface `DomainEvent`. Tests unitaires.
- Squelette `contexts/ledger/{ledger-domain, ledger-application, ledger-infrastructure, ledger-boot}` avec les dépendances de la section 11.2 du dossier ; `LedgerApplication` démarre (port 8002, threads virtuels) et un test `@SpringBootTest` le vérifie.
- `tests/architecture` : `ArchitectureTest` avec `domainIsPure`, `sharedKernelIsPure` et `contextsAreIsolated`. Vérifié : une classe annotée `@Component` ajoutée temporairement dans `ledger-domain` fait échouer le build.
- `deploy/docker-compose.yml` : PostgreSQL 16 avec healthcheck ; script d'init qui crée la base `ledger` et le rôle `ledger_app` ; secrets dans `deploy/.env` (modèle `deploy/.env.example`).
- CI GitHub Actions (`.github/workflows/ci.yml`) : job `build` (`./gradlew build`, rapports de tests en cas d'échec, couverture JaCoCo en artefact) et job `compose` (démarrage `--wait`, `pg_isready` sur `ledger`, arrêt).

## Vérifié en local

- `./gradlew build` vert avec JDK 25.
- `docker compose -f deploy/docker-compose.yml up -d --wait` : conteneur sain, connexion `ledger_app` sur la base `ledger`.

## Ce qui a été appris

- Le Gradle global (8.13) ne tourne pas sur Java 25 : tout passe par le wrapper (ADR-15).
- ArchUnit échoue par défaut sur une règle qui ne vérifie aucune classe (`failOnEmptyShould`) ; utile pour éviter une règle silencieusement vide, mais gênant tant que le domaine est vide.
- Le script d'init de PostgreSQL ne s'exécute qu'avec un volume vide : changer le rôle ou le mot de passe demande `docker compose down -v`.
