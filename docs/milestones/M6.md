# M6 — Simulateurs PI-SPI, opérateurs, banques, pannes

Branche : `milestone/m6-simulators` · Taille : M

## Ce qui a été construit

- **`simulators/common`** : `FaultQueue`, modes documentés, `HmacSigner`,
  `CallbackDispatcher`, `POST /control/faults` (ADR-24).
- **`simulators/pispi`** (9101) : `POST /transfers`, `GET /transfers/{id}`,
  `POST /control/inbound` (webhook signé), `GET /reports/settlement?date=`.
- **`simulators/mno`** : collections, décaissements, float, statut, fichiers
  de règlement ; instances Compose `mno-wave` (9102) et `mno-orange` (9103).
- **`simulators/bank`** : `POST /control/credit`, `GET /statements` écrit un
  CSV S3 ; instances `bank-a` (9104) et `bank-b` (9105).
- **Compose** : magasin d'objets S3-compatible (Adobe S3Mock sur 9000) + cinq
  simulateurs. CI construit les jars et vérifie la santé 9101–9105.
- **Tests** : un IT par mode de panne (réponse ou callback) ; inbound PI-SPI
  signé ; relevés `missing_statement_line` / `wrong_amount` sur S3Mock.

## Tests

- MNO : `reject` → 422 ; `latency` ≥ délai ; `timeout_then_*` puis callback ;
  `duplicate_callback` ×2 ; `out_of_order_callback` (failed puis succeeded) ;
  `float_exhausted` sans bouger le float.
- PI-SPI : reject / latency / timeout_then_success ; inbound → webhook HMAC +
  ligne de règlement.
- Bank : objet CSV dans S3 ; ligne manquante ; montant altéré (+1).

## Ce qui a été appris

- Spring Boot 4 n'expose pas toujours un bean `RestClient.Builder` : le
  déclarer dans la config commune.
- Jackson 3 (`tools.jackson`) pour la sérialisation des callbacks ; annotations
  `com.fasterxml.jackson` restent valides pour les enums.
- L'image Docker Hub `minio/minio` n'était pas tirable ici ; S3Mock suffit
  pour le chemin S3 path-style utilisé par le simulateur banque.
- S3Mock écoute sur **9090** dans le réseau Compose ; le mapping hôte
  `9000:9090` ne change pas l'endpoint inter-conteneurs (`http://minio:9090`).
- Pour `timeout_then_*`, le store doit passer à l'état final après le délai
  (pas seulement le webhook), sinon les enquêtes de statut M7 restent bloquées
  sur `pending`.
